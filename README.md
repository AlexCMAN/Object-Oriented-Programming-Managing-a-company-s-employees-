# Object Oriented Programming - Academic Project (Managing a company's employees)

## Description
This repository features a C++ desktop application built to manage company structures, staff profiles, and payroll systems. Developed as an academic project, it focuses on implementing fundamental Object-Oriented Programming (OOP) principles, clean software architecture, and reliable data management.

## Key Features
* **Employee Management:** Tools to add, update, and remove employee profiles across various company departments.
* **Payroll Processing:** Automated data processing logic for calculating salaries, benefits, and structural payroll.
* **Strict Data Validation:** Comprehensive input handling routines to prevent errors and ensure data integrity.

## Tech Stack & Tools
* **Programming Language:** C++
* **Core Concepts:** Object-Oriented Design (Encapsulation, Inheritance, Polymorphism), Exception Handling, Data Modeling.
